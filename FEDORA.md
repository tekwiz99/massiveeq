# Fedora port

This fork carries an unofficial Fedora 44 port of MassiveEQ.

See [`fedora/README.md`](fedora/README.md) for the full instructions, and:

- [`fedora/massiveeq-fedora-install.sh`](fedora/massiveeq-fedora-install.sh) — build & install from source
- [`fedora/massiveeq.spec`](fedora/massiveeq.spec) — RPM spec (rpmbuild / COPR / mock)

Upstream MassiveEQ supports Arch Linux only; Fedora packaging is community maintained.
